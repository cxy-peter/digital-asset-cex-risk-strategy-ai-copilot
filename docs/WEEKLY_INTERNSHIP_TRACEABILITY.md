# 四周实习到项目的追溯

## 第一周：系统和流程认知

- 学习CMS/STR、MASAK XML、风控后台、审计和产品验收；
- 映射为：CMS/STR内部候选、人工复核、端到端测试边界。

## 第二周：产品流程和安全治理

- 学习BRD/PRD、处罚审批、RBAC、数据字段缺口；
- 映射为：审批门禁、最小权限、版本审计和配置Schema。

## 第三周：数据、模型和风险场景

- 接触数仓字段、用户风险评分、策略回溯、Risk Graph、专家规则和XGBoost；
- 映射为：特征目录、模型基线、图谱特征、策略DSL和回测。

## 第四周：产品体系和策略生命周期

- 研读FEP、规则引擎、三层标签、工单效果打标、STR历史、AI辅助配置和完整策略SOP；
- 映射为：公司式测试环境、效果工单、CMS/STR联动和多Agent原型。
